บันทึกผลทดสอบ

เกณฑ์การอ่านผล: เปรียบเทียบทุกภาวะกับ reference ซึ่งเก็บที่อุณหภูมิห้อง และกำหนดเป็นสัญลักษณ์การอ่านผลดังนี้
ผลการสังเกตบันทึกการเปลี่ยนแปลงทางกายภาพที่สังเกตได้ (สี, กลิ่น, เนื้อสัมผัส, ตะกอน/แยกชั้น)
ผลการวิเคราะห์0 = ไม่เปลี่ยนแปลง  |  -1/-2/-3 = ลดลงเล็กน้อย/ปานกลาง/มาก  |  +1/+2/+3 = เพิ่มขึ้นเล็กน้อย/ปานกลาง/มาก
แต่ละ checkpoint แสดงเฉพาะเงื่อนไขที่ต้องทดสอบจริงตามแผนงาน — กด "บันทึก" ในแต่ละช่วงเพื่อบันทึกทีละ checkpoint ได้เลย หรือกด ✕ มุมบนขวาเพื่อบันทึกทั้งหมดแล้วปิดในทีเดียว
