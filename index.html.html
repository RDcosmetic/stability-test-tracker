บันทึกผลทดสอบ

เกณฑ์การอ่านผล Texture/Color/Odor/Viscosity: เปรียบเทียบกับ reference ที่เก็บที่อุณหภูมิห้อง — 0 = ไม่เปลี่ยนแปลง  |  -1 = ลดลงเล็กน้อย, -2 = ลดลงปานกลาง, -3 = ลดลงมาก  |  +1 = เพิ่มขึ้นเล็กน้อย, +2 = เพิ่มขึ้นปานกลาง, +3 = เพิ่มขึ้นมาก
แต่ละ checkpoint แสดงเฉพาะเงื่อนไขที่ต้องทดสอบจริงตามแผนงาน — กด "บันทึก" ในแต่ละช่วงเพื่อบันทึกทีละ checkpoint ได้เลย หรือกด ✕ มุมบนขวาเพื่อบันทึกทั้งหมดแล้วปิดในทีเดียว
